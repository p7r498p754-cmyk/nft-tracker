# Тестовый перенос Stars на Cloudflare

`stars-staging.mjs` принимает события формата Telegram и сохраняет тестовые квитанции в отдельной D1. Заказы имеют префикс staging-. У стенда нет токена бота и вызовов Telegram API. Доступ в стенде отделён от пользовательских подписок.

Ресурсы стенда называются nft-tracker-stars-staging. Worker загружен без активного маршрута. Для изолированного HTTP-прогона нужен секрет STAGING_WEBHOOK_SECRET в секретах Worker и временный маршрут только для тестового окружения. База подключается под именем LEDGER. Схема хранится в stars-staging.sql. GET /health проверяет доступность таблицы и возвращает статус без данных заказов. Для POST /telegram, /fixtures/order и /fixtures/access нужен заголовок X-Telegram-Bot-Api-Secret-Token.

Проверка локально на Node.js 24: `node --test cloudflare/stars-staging.test.mjs`. Тест проходит через HTTP-обработчик и настоящую SQLite. Он покрывает неверный секрет, размер запроса, подмену суммы и пользователя, повторное подтверждение, запись успешной оплаты и возврат.

До переключения действующего бота остаются подключение отдельного тестового бота Telegram, перенос обработки команд и интеграция оплаченного доступа с мониторингом, проверка резервного восстановления журнала и канал поддержки покупателей. GitHub Actions продолжает принимать обновления действующего бота до переключения.
